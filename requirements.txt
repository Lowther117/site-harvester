# Site Harvester - runtime + build requirements (Windows, macOS and Linux)

# Every package here has a floor (the oldest version these scripts were
# tested with) and a ceiling at the next major version. A new major is
# something to opt into after a test build, never something a routine
# rebuild discovers for you - PyMuPDF 2.0 broke two builds that way (Nov 2026).
# (yt-dlp is date-versioned and must track the sites it downloads from, so it
# has no ceiling.)
requests>=2.31.0,<3
beautifulsoup4>=4.12.0,<5
yt-dlp>=2024.1.1
playwright>=1.40.0,<2
pypdf>=4.0.0,<7

# Build-time only: turns the script into a double-clickable app.
pyinstaller>=6.11,<7

# NOTE ON PDF OUTPUT
# The PDF is produced by the headless Chromium that Playwright installs, and
# the pages are merged with pypdf. Both are above, so PDF output works out of
# the box on every platform.
#
# WeasyPrint is only a lower-fidelity fallback for when Chromium cannot start.
# It is deliberately NOT listed here: on Windows it additionally needs the Pango
# system libraries via MSYS2, which is a heavy prerequisite for a fallback that
# should never run. To install it anyway:
#
#     pip install -r requirements-fallback.txt
